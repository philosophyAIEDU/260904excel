# 명단 대조 도구 (Roster Diff Tool)

인사/명단 관리 업무에서 반복되는 `COUNTIF(기존,신규)` / `COUNTIF(기존,누락)` 수작업을
대체하기 위한 **완전 클라이언트 사이드** 웹 도구입니다. 기존 명단(A)과 새로 받은 명단(B)을
주민등록번호(또는 지정한 컬럼) 기준으로 비교해 **신규자 / 누락자 / 유지자**를 자동으로
분류하고, 그 외에도 COUNTIF·SUMIF·VLOOKUP·중복 찾기 기능을 함께 제공합니다.

## 🔒 보안 안내 (필독)

- 이 도구는 **순수 HTML + JavaScript 단일 파일(`index.html`)**로 만들어져 있으며,
  엑셀 처리 라이브러리(SheetJS)도 파일 안에 완전히 인라인으로 포함되어 있습니다.
  인터넷 연결 없이 `index.html`을 더블클릭해서 열어도 그대로 동작합니다.
- **업로드한 파일은 어떤 서버로도 전송되지 않습니다.** 백엔드 서버, 외부 API 호출,
  클라우드 저장, AI API(OpenAI/Claude API 등) 호출이 전혀 없으며, 모든 읽기·비교·계산·
  엑셀 생성이 사용자의 브라우저 안에서만 이루어집니다.
- **이름, 주민등록번호, 계좌번호 등 개인정보는 브라우저 메모리에서만 처리되며,
  로컬 저장소(localStorage/sessionStorage)나 서버·저장소 어디에도 저장되지 않습니다.**
  탭(창)을 닫으면 데이터는 즉시 사라집니다.
- 화면 미리보기·결과 테이블에서는 "주민번호"가 포함된 컬럼이 기본적으로 마스킹되어
  표시됩니다(예: `901231-1●●●●●●`). 상단의 "주민번호 표시/숨김" 토글로 필요할 때만
  전체 번호를 확인할 수 있습니다. 단, **다운로드되는 엑셀 파일에는 항상 원본 값 그대로**
  저장되며, 마스킹은 화면 표시에만 적용됩니다.
- `.gitignore`에 `*.xlsx`, `*.xls`, `*.csv`를 등록해 실제 명단 파일이 실수로
  저장소에 커밋되는 것을 방지하고 있습니다.

## ✨ 주요 기능

### 1. 명단 대조 (메인 기능)
- "기존 명단"과 "새로 받은 명단"을 업로드하고 비교 기준 컬럼을 선택하면
  (컬럼명이 "주민번호"이면 자동 선택)
  - **신규자**: 새로 받은 명단에는 있지만 기존 명단에는 없는 사람
  - **누락자**: 기존 명단에는 있지만 새로 받은 명단에는 없는 사람
  - **유지자**: 양쪽 모두에 있는 사람
  세 그룹으로 자동 분류합니다.
- 그룹별 인원수를 큰 숫자로 강조 표시하고, 탭으로 전환하며 표로 확인할 수 있습니다.
- 전체 결과를 신규자/누락자/유지자 3개 시트로 구성된 엑셀 파일로 다운로드할 수 있습니다.

### 2. 조건별 개수 세기 (COUNTIF)
파일/컬럼/조건(같음·다름·포함·이상·초과·이하·미만·비어있음·값있음)/조건값을 지정하면
조건에 맞는 개수를 계산합니다.

### 3. 조건별 합계 (SUMIF)
조건에 맞는 행을 찾아 지정한 숫자 컬럼의 합계를 계산합니다. 숫자가 아닌 값은
합계에서 자동으로 제외되며 몇 건이 제외되었는지 함께 표시합니다.

### 4. 값 가져오기 (VLOOKUP)
기존 명단의 기준 컬럼과 새로 받은 명단의 매칭 컬럼을 지정하고, 가져올 컬럼을
(다중 선택) 지정하면 새 컬럼으로 값을 붙여줍니다. 매칭되지 않으면 "매칭없음"으로 표시됩니다.

### 5. 중복 찾기
기준 컬럼(다중 선택 가능)을 지정하면 값이 동일한 행들을 그룹으로 묶어
중복 그룹 번호를 매기고, 중복된 행만 추출합니다.

모든 텍스트 비교(이름, 주민번호 등)는 앞뒤 공백 제거 + 대소문자 무시 방식으로 이루어집니다.
여러 시트가 있는 파일은 시트 선택 드롭다운이 자동으로 표시됩니다.

## 🖱️ 사용 방법

1. **파일 업로드**: 기존 명단(A)과 새로 받은 명단(B)을 업로드합니다. (xlsx, xls, csv 지원)
2. **기능 선택**: 상단 카드에서 원하는 기능(명단 대조 / COUNTIF / SUMIF / VLOOKUP / 중복 찾기)을 선택합니다.
3. **조건 입력**: 드롭다운 위주의 입력창에서 비교 기준·조건을 입력합니다.
4. **결과 확인 및 다운로드**: 화면에서 결과를 확인(최대 50행 미리보기)한 뒤 "엑셀로 다운로드" 버튼으로 전체 데이터를 내려받습니다.

## 🛠️ 기술 스택

- 순수 HTML + Vanilla JavaScript (프레임워크 없음)
- 엑셀 처리: [SheetJS (xlsx)](https://sheetjs.com/) — CDN이 아닌 파일 내부 인라인 번들
- 단일 `index.html` 파일로 배포 (별도 빌드 과정 불필요)

```bash
open index.html   # macOS

```
